# Виза Испания — документы и процессы

Одностраничное поле, на котором собран пакет документов для подачи 25–27 октября.
Работает без сервера: состояние живёт в браузере и выгружается в `data.json`.

## Как читать

- **Строка — один документ и весь его путь.** 17 строк = 17 позиций пакета.
- Слева направо: сам документ → апостиль → перевод. Справа — пунктирная линия и карточка «Подача».
- Сплошная рамка — документ, пунктир — процесс.
- Полоска слева: синий — Артём, фиолетовый — жена, красный — Глеб, золотой — общее.
- Притушённая карточка ждёт вход. Панель «Сейчас можно» слева — только то, что не заблокировано.

## Что можно делать

- Тап по чипу статуса: не начат → в работе → готов.
- Карточку тянуть — она встаёт в ряд встык, золотая полоса показывает куда. Если тянуть в промежуток между рядами, появится новый ряд.
- Кружок справа на карточке — потянуть на другую карточку, получится зависимость. Клик по связи — убрать.
- «Сохранить JSON» кладёт `data.json` на диск, «Открыть JSON» поднимает его обратно.

## Сборка

`index.html` — это `app.html` + `data.json`, зашифрованные паролем. На сервере лежит только шифротекст.

```bash
python3 gen_data.py          # пересобрать data.json из списка документов
python3 build.py gleb        # собрать index.html под паролем
```

Шифрование: AES-GCM 256, ключ из пароля через PBKDF2-SHA256, 250 000 итераций.
Расшифровка — в браузере, WebCrypto. Пароль в пределах вкладки помнится, между сессиями спрашивается заново.
