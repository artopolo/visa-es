# ВНЖ Испания — документы

Одна страница со всеми документами на подачу. Мобайл первым, вертикальный скролл,
автосохранение на сервер. Вход по паролю, приложение на сервере лежит зашифрованным.

## Как устроено

- **Карточка = документ.** Внутри — водопад пунктов: следующий открывается, когда закрыт предыдущий.
- **Цвет карточки** ровный и непрозрачный, один и тот же голубой на все незакрытые,
  прохладный зелёный на готовой, белый на паузе. Заливка глухая, чтобы фон не подкрашивал
  одинаковые карточки по-разному. Никаких градиентов, размытий и движения внутри карточек —
  только ровный тон и общее зерно поверх страницы.
- На паузе гаснут пункты, но файлы грузятся и открываются как обычно.
- **Внизу карточки** — кружки по числу пунктов, каждый цвета своего исполнителя: пустой — впереди,
  залитый — закрыт. При раскрытии они перелетают и становятся кружками пунктов, при закрытии — обратно.
  Карточка перетаскивается за точки слева.
- **Внутри пункты сгруппированы по людям**: имя написано один раз над блоком. Тап по имени
  переназначает весь блок.
- Название и заметка правятся на месте: двойной клик, либо один клик на раскрытой карточке.
- Кружок у пункта — кто им занят. Тап по кружку меняет исполнителя.
  Новый пункт: название, потом светофор Артём / Аня / Глеб — выбор цвета и есть добавление.
- Пункты можно добавлять и убирать, к каждому — заметка.
- Файлы грузятся прямо в карточку, лежат в приватном бакете, открываются по временной ссылке.

## Виды

1. **Документы** — всё подряд, с раскрытием.
2. **Кто за что** — на каждого: документы, а под ними его пункты, доступные и ждущие.
   Тумблер «сделанные» показывает закрытые пункты; по ним же можно снять галочку.
3. **Файлы** — те же карточки, раскрытые сразу на вложениях, без пунктов и заметок.
   Сверху кнопка «Скачать всё одним архивом» с числом файлов и весом: браузер тянет их
   по подписанным ссылкам и собирает zip на месте, без сжатия и без внешних библиотек.

## Отмена

⌘Z и ⇧⌘Z, либо стрелки в шапке. Хранится 80 последних состояний.

## Сервер

Supabase, проект `sjjktpnpfdwolihydbdh`. Общая схема на несколько приложений:

- `public.app_state (app, doc jsonb, updated_at)` — одна строка на приложение, у этого `app = 'visa'`.
- бакет `apps`, папка `visa/<карточка>/<файл>` — приватный, доступ по подписанной ссылке.

Так же сюда можно посадить любой следующий проект: новая строка в `app_state`, своя папка в бакете.

Сохранение — через 0.7 секунды после правки, плюс опрос сервера раз в 20 секунд, чтобы
подхватывать чужие изменения. Кто сохранил последним, того и версия: троим этого хватает,
одновременная правка одной карточки может затереть соседа.

## Сборка

```bash
python3 gen_data.py       # список документов -> data.json
python3 build.py gleb     # app.html + data.json + supabase.json -> index.html (шифр)
```

AES-GCM 256, ключ из пароля через PBKDF2-SHA256, 250 000 итераций. Расшифровка в браузере.

Вход — обычная форма с настоящей отправкой: по этой навигации Safari и предлагает сохранить
пароль в связку ключей, а потом подставляет его сам. У полей нет атрибута `name`, поэтому
в адресную строку пароль не попадает; на время вкладки он лежит в sessionStorage.
`supabase.json` содержит ключ доступа к базе — он попадает внутрь шифра, в открытый репозиторий
кладётся только `index.html`.
